# Backend-Web-2025  
## Лабораторная 4

- **Цель работы**: завершение бэкенда для SPA  
- **Порядок показа**  
  1. Авторизация через Swagger (инкогнито) → получение JWT / установка сессии.  
  2. Swagger: GET /api/orders – 401 для гостя; для создателя только свои; для модератора – все.  
  3. Insomnia/Postman:  
     - скопировать `Cookie: sessionid=…` или `Authorization: Bearer &lt;JWT&gt;` из вкладки Application / ответа auth.  
     - GET /api/orders – проверка фильтрации.  
     - PUT /api/orders/{id}/complete – 403 для создателя, 200 для модератора + обновление даты завершения.  
  4. CLI: `redis-cli KEYS "*session*" | xargs redis-cli GET` – показать сериализованные сессии и имя пользователя.  
  5. StarUML: Sequence-диаграмма «Бизнес-процесс без БД» – Lifeline=домены, сообщения=методы из диаграммы классов, signature переиспользованы.

- **Контрольные вопросы**  
  куки vs сессия, хранилище Redis, JWT-структура, авторизация и аутентификация, SSO, 2FA, RSA-пара ключей.

- **Sequence-диаграмма** (файл `docs/sequence_auth.png`)  
  Аутентификация → Список услуг → Корзина пуста → Добавить услугу → Корзина с 1 → Просмотр черновика → Редактировать → Сформировать → Список заявок → Модератор завершает → Список с расчётом.

- **Задание**  
  1. Реализовать `/auth/login`, `/auth/register` – сессии в Redis, JWT-опция.  
  2. Swagger-документация: автозаполнение `creator_id` при POST /orders.  
  3. Permissions:  
     - гость – только GET /services, GET /services/{id}  
     - создатель – все свои методы  
     - модератор – всё + PUT /orders/{id}/complete, POST/PUT/DELETE /services  
  4. Подготовить полный комплект документации:  
     - РПЗ.docx (титул, 3 рисунка-диаграммы, расчёт железа)  
     - Приложение 1: ТЗ (сплошная нумерация)  
     - Приложение 2: Таблица методов API (14 строк)

- **Функциональные требования (ТЗ)**  
  | № | Экран / метод | Доступ | Бэкенд-ручки |
  |---|---------------|--------|-------------|
  | 1 | Регистрация | гость | POST /auth/register |
  | 2 | Аутентификация | гость | POST /auth/login |
  | 3 | Главная | все | GET /api/services?promo=true |
  | 4 | Список услуг | все | GET /api/services |
  | 5 | Карточка услуги | все | GET /api/services/{id} |
  | 6 | 403 / 404 | все | – |
  | 7 | Корзина (черновик) | создатель | GET /api/orders/current |
  | 8 | Добавить в корзину | создатель | POST /api/orders/current/items |
  | 9 | Сформировать заявку | создатель | PUT /api/orders/{id}/submit |
  |10 | Список моих заявок | создатель | GET /api/orders?filter=my |
